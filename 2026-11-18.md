# 2026-11-18 — Semaine 12

## Contexte

Dans le cours d'aujourd'hui, nous avons visionné les projets EVS3 de tout le monde, puis nous avons commencer à travailler sur notre projet finale, dans lequel nous allons créé une courte vidéo avec sons (environs 1m30sec).

## Pitch du projet finale

Pour mon projet final, je prévois de faire une présentation du jeu BeamNG Drive, les raisons pour lequels j'aime ce jeu et le coeur de ce dernier.

## Intégration médiatique

Dans mon projet, je prévois d'utiliser les médiums suivant:
- **Vidéo:** Je vais utiliser beaucoups d'enregistrements vidéos sur le jeu, afin de présenter tout mes éléments.
- **Voix:** Avec la vidéo, je décrirai les points forts du jeu en voix-off, sur un ton légèrement humoristique.
- **Musique:** Pour garder l'attention, je mettrai une musique d'ambiance énergique qui collera avec le ton de la voix-off.
- **Image:** Pour certains éléments n'étant pas à l'intérieur du jeu, j'utiliserai des images des sources officiels de BeamNG Drive.
